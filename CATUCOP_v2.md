# Contexto
Estamos contruyendo un sitio web para una camara de turismo especificamente para la de Puerto Jimenez, un canton relativamente nuevo y pequeño en Costa Rica. Actualmente tienes acceso a un pryeto en figma el cual contiene las variables diseño y distribucion de la pagina web, ademas cree un archivo html de un mapa interactivo sobre la peninsula de osa el cual debemos valorar si vale la pena agregar, hay muchas cosas que tomar en cuenta:
  - La pagina web esta hecha en wordpress debemos crearla en un entorno local (la carpeta ya fue adjuntada como: catucop_2.0) el cual debe ser replicado en un servidor de produccion. 
  - La pagina web debe ser responsiva y funcionar correctamente en todos los dispositivos y navegadores, ademas debe estar en español y en ingles.
  - La pagina web debe ser optimizada para SEO y tener tiempos de carga rápidos (para esto se debe hacer un plugin que administre las metatags y meta desc de las paginas que se crean (index, afiliados, lugares y horaios)).
  - La pagina web debe tener un sistema de gestión de contenido (CMS) que permita a los administradores del sitio actualizar fácilmente el contenido (agregar afiliados, eventos, horarios, direcciones y destinos turisticos nuevos en el mapa interactivo).
  - La pagina web debe tener un diseño atractivo y profesional que refleje la identidad de la camara de turismo de Puerto Jimenez. siendo fiel al diseño proporcionado en Figma.
  - La posicion de los afiliados debe ser definida de forma aleatoria cada vez que se cargue esa pagina para evitar favoritismos, pero debe ser posible que los administradores puedan cambiar la posicion de los afiliados si asi lo desean.
